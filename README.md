# hopper-documentation-anth

[English](hopper-documentation-anth-en/README.md) | [Português (Brasil)](hopper-documentation-anth-pt-br/README.md)

A Claude Code plugin that records the conversation in Markdown handoffs, on request and before each compaction, so another person or session can continue the work, on macOS and Linux.

Um plugin do Claude Code que registra a conversa em handoffs Markdown, a pedido e antes de cada compactação, para que outra pessoa ou sessão continue o trabalho, em macOS e Linux.

Choose one language and install its complete plugin: the skill, the writer rules, the program, and the hook. The plugin and the skill are named `hopper-documentation-anth` in both languages. Follow the language README to verify the CLI and the app separately.

Escolha um idioma e instale seu plugin completo: a skill, as regras do redator, o programa e o gatilho. O plugin e a skill se chamam `hopper-documentation-anth` nos dois idiomas. Siga o README do idioma para verificar a CLI e o aplicativo separadamente.

Each release includes both languages. The language folders separate documentation and packages; the installed name remains `hopper-documentation-anth`.
